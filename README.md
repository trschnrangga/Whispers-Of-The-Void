# Whispers Of The Void | Object Oriented Project


**Whispers Of The Void** is a _Vampire Survivors_ like game with most of the assets handmade, it also is different with _Vampire Survivors_ as in **Whispers Of The Void** you need to aim your shots and a dash mechanic

Created in Godot with C# as the language, created in a span of 2 weeks-ish
